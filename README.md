# HomeLab

Enterprise Home Lab focused on Infrastructure, Networking, Virtualization, Automation, Security and Observability.

This repository documents the planning, architecture, implementation and evolution of a personal enterprise-style HomeLab. The goal is to build a production-inspired environment while following industry best practices for infrastructure design, documentation, automation and operations.

---

## Project Goals

* Build an enterprise-inspired HomeLab
* Learn and validate infrastructure technologies
* Improve networking and security knowledge
* Practice virtualization and containerization
* Document architectural decisions
* Automate infrastructure whenever possible
* Maintain a professional technical portfolio

---

### Infrastructure

* OPNsense

* DNS
* VPN
* MQTT

### Monitoring

* Grafana
* Prometheus
* Uptime Kuma

### Home Automation

* Home Assistant
* Node-RED
